## 개요

성인 전기 과정에서 개발할 게임은 14개입니다. 전1-1은 이미 개발이 끝났고, 남은 13개 중 이미지가 다 갖춰진 게임은 6개입니다.

- 분석한 문서: `docs/게임개발요청_생애주기_전기_1,5,6,7단원.hwp`(10월 25일, 최신)와 `docs/생애주기_게임개발요청사항_3,4,5,7단원.hwp`(10월 6일). data 폴더의 `.hwpx` 상세 기획서 2개(전5-3 도입, 전7-1)도 함께 봤습니다.
- 두 요청서 내용이 다를 때는 10월 25일 문서를 기준으로 했습니다. 다른 부분은 각 게임 설명에 적어 두었습니다.
- 기준 구현: `data/dk`에 있는 전1-1 「오늘의 PICK」입니다. 디자인 시안 6개(typeA~F)와 시안 선택 페이지(index.html)가 들어 있습니다.

## 전1-1 재사용과 개발 순서
